## 4. 공개 인터페이스
```python
# pyproject 핵심
[project] name="loom" requires-python=">=3.12"
dependencies = ["pydantic>=2", "pydantic-settings", "python-ulid", "typer", "rich"]
[dependency-groups] dev = ["pytest", "ruff", "import-linter"]
[tool.pytest.ini_options] markers = ["integration", "llm", "slow", "gpu"]
addopts = "-q -m 'not integration and not llm and not slow and not gpu'"
```

- ruff 설정: line-length 100, select E,F,I,B,UP
- `tests/test_smoke.py`: 모든 섹터 public import 가능 확인
