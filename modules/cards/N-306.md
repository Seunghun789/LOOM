# N-306 · 매핑 DSL·매퍼

> 섹터 **connect** · 마일스톤 **M3 Connect (S2)** · 우선 **P0** · 크기 **M** (≈1.5 세션) · 담당 서브에이전트 **module-builder**

## 1. 목표
YAML 규칙으로 RawRecord → Entity. 원천 위치를 provenance.source에 기록.

## 2. 의존
- N-302 — CSV·Excel 커넥터
- N-303 — 시계열 커넥터 → TelemetryStore
- N-304 — 텍스트 로그 커넥터
- N-305 — PDF 커넥터 (Docling)

## 3. 생성·수정 파일
- `src/loom/connect/mapping.py`
- `src/loom/connect/mappings/spine20.yaml`
- `tests/connect/test_mapping.py`

## 4. 공개 인터페이스
```python
class MappingRule(BaseModel): name; connector; file_glob; entity_type; id_template  # '{site}:Equipment:{id}'
    title_field; properties: dict[str, PropMap]; relationships: dict[str, RelMap]
class Mapper: def __init__(rules, site, run_id); def map(record: RawRecord) -> list[Entity]
```

## 5. 구현 단계
- id_template 치환은 str.format + 필수 필드 누락 시 MappingError
- PropMap: field, unit, transform(float|int|date|str)
- RelMap: field, target_type, id_template
- spine20.yaml: equipment/lots/inspections/alarms 규칙 (정비일지·PDF는 S3 추출이 담당)
