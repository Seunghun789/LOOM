## 4. 공개 인터페이스
```python
class CriterionCandidate(BaseModel): item: str; target_class: str; prop: str; op: Literal['>=','<=','between','==']; value: float | tuple[float,float]; unit: str; period: str | None; section_ref: str
class DocExtraction(BaseModel): doc_id; version; effective: date | None; criteria: list[CriterionCandidate]
extract_document(records: list[RawRecord], model: BaseChatModel) -> DocExtraction
to_entities(ex: DocExtraction, site, run_id) -> list[Entity]  # Document, Criterion(+governs → Parameter), 모두 ASSUMED
```

## 5. 구현 단계

- model.with_structured_output(DocExtraction)
- 프롬프트는 파일로 분리, 버전 태그
