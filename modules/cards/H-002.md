# H-002 · import-linter 경계 규칙

> 섹터 **harness** · 마일스톤 **M0 Harness Bootstrap** · 우선 **P0** · 크기 **S** (≈1 세션) · 담당 서브에이전트 **contract-guardian**

## 1. 목표
docs/02_CONTRACTS.md §1 B-1~B-5를 기계가 검사하게 만든다.

## 2. 의존
- H-001 — 저장소 골격·uv·pytest·ruff

## 3. 생성·수정 파일
- `.importlinter`
- `tools/check_boundaries.sh`

## 4. 공개 인터페이스
```python
[importlinter]
root_package = loom
[importlinter:contract:core-independent]  type = forbidden ...
[importlinter:contract:public-only] type = forbidden  # loom.X.* (public 제외) ← loom.Y
[importlinter:contract:layers] type = layers
```

## 5. 구현 단계
- core 독립 계약(forbidden)
- 섹터 간에는 `public`만 허용하는 계약 — 섹터마다 `loom.<s>.public` 외 하위모듈 import 금지
- B-5 허용 방향을 layers 또는 forbidden 조합으로 표현
- `tools/check_boundaries.sh` = `uv run lint-imports`

## 6. 수용 테스트 (Definition of Done)

- [ ] `uv run pytest -q` 전체 통과 · `uv run ruff check` · `uv run lint-imports` 통과
