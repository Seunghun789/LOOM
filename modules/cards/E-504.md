# E-504 · 온톨로지 RAG 질의 그래프

> 섹터 **evidence** · 마일스톤 **M5 Evidence + Eval (S6) → G1** · 우선 **P0** · 크기 **M** (≈1.5 세션) · 담당 서브에이전트 **module-builder**

## 5. 구현 단계
- 노드: route → resolve → expand → gather(도구 병렬 호출) → hypothesize(원인 후보 점수: 시간 선행성·이상 크기·경로 길이) → verify_evidence(A-1·A-3) → compose(LLM, role='reason')
- insufficient 판단은 E-506 정책 호출
- 각 노드 Tracer span
- RCA 점수는 **규칙 기반 점수 + LLM 재정렬**의 2단 (재현성)
