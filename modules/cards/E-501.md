## 4. 공개 인터페이스
```python
class Doc(BaseModel): id; kind: Literal['chunk','entity_card']; urn: str | None; text; meta: dict
class HybridIndex:
    def __init__(self, embedder: Embedder, reranker: Reranker | None = None)
    def add(self, docs: list[Doc]) -> None
    def search(self, query: str, k=8, filters: dict | None = None) -> list[tuple[Doc, float]]
entity_card(e: Entity) -> Doc   # 사람이 읽는 한 단락
class Reranker(Protocol): rerank(query, docs) -> list[float]
```
