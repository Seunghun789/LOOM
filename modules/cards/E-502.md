# E-502 · 질의 도구 세트 (@tool)

> 섹터 **evidence** · 마일스톤 **M5 Evidence + Eval (S6) → G1** · 우선 **P0** · 크기 **M** (≈1.5 세션) · 담당 서브에이전트 **module-builder**

## 4. 공개 인터페이스
```python
make_tools(ctx: EvidenceContext) -> list[BaseTool]
  resolve_entities(text) -> [{urn, title, score}]
  entity_facts(urn, props=None) -> {facts, steps}
  graph_neighbors(urn, k=1, types=None) -> {nodes, steps}
  graph_paths(src, dst) -> {paths}
  telemetry_window(urn, prop, start, end, agg='mean|max|trend') -> {series_summary, steps}
  doc_search(query, doc_version_at=None) -> {chunks, steps}
  criteria_at(urn, prop, at) -> {criteria, steps}
class EvidenceContext: store; telemetry; graph; index; matcher; now
```
