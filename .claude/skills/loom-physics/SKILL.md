# 물리·서로게이트 규칙

## 원칙 (E8 NFLOW Ai에서 가져옴)
1. **솔버가 기준(ground truth)**, 서로게이트는 스크리닝 도구
2. 서로게이트 결과에는 항상 **신뢰구간 + OOD 여부**
3. 물리 결과로 설비를 직접 제어하지 않는다 → **자율 레벨 L1 고정**

## 솔버 검증 순서 (F-1002)
| 단계 | 케이스 | 합격 |
|---|---|---|
| 1 | 2D 채널 포아죄유 흐름 | 속도 프로파일 해석해 대비 오차 < 3% |
| 2 | 열원 없는 등온 | 온도장 균일 유지 |
| 3 | 열원 1개 | 하류 온도 상승, 에너지 수지 잔차 < 5% |
통과 전에는 스윕·서로게이트 카드로 넘어가지 않는다.

## 계산 자원
- 기본 격자 128×128, numpy 백엔드, 케이스당 < 60s (M1/M2 맥 CPU 기준 목표)
- GPU·XLB 경로는 `@gpu` 마커, CI 기본 제외

## 데이터셋 규약 (F-1003·F-1004)
- `var/sim/<template>/<run_id>.npz`: `params`(1D), `T`(H×W), `ux`, `uy`, `meta`(json)
- 학습/검증/보정(컨포멀) = 60/20/20, seed 고정
- SimulationRun 엔티티: params·결과 경로·솔버 버전·잔차

## 서로게이트 보고 필수 항목
MAE(°C) · 최대온도 오차 · 검증셋 커버리지(컨포멀 α=0.1 → 목표 ≈90%) · OOD 경계 샘플 결과 · 추론 시간

## 최적화 → 권고
1. 서로게이트로 격자 탐색 N=200
2. 제약 만족 상위 3개를 **솔버로 재계산** (AI-CFD 하이브리드)
3. 솔버 결과로 최종 선택 → `Decision(autonomy=L1)`, `ProposedAction.predicted_by=SimulationRun URN`
